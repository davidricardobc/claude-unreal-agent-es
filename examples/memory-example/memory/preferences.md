# Preferencias

- Frases cortas, viñetas, primero lo que necesita acción.
- Volumen por defecto bajo; siempre un control de volumen en el juego y en la configuración.
- El daño no debe castigar los controles.
- Push, publicar, créditos de pago: solo con un sí explícito para esa acción.
- Si pide revisar: no toques nada; primero una tabla y notas.
