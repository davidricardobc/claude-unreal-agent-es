# Proyecto actual

## Objetivo
TableFlyer: un avión de papel sobre un escritorio gigante. Un nivel arcade (puntaje, enemigos, daño por choque) y un nivel de práctica de vuelo libre.

## Hecho
- Rondas 1 a 7: vuelo, dash, aros, globos, aviones enemigos, daño por choque en 4 etapas, 8 aviones, cuarto con luz real, nivel de práctica, modo "piloto" opcional con loops. Empaquetado y probado con sonido.
- Ronda 8: guía de importación de Blender a UE probada con FBX y GLB; combo y contrarreloj; las 8 skills del pipeline de juego usadas de verdad (10 arreglos volvieron a las skills).
