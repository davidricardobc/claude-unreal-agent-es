# Ejemplo de memoria

Una memoria real, recortada y hecha genérica, de un agente que construyó un juego arcade pequeño de UE 5.8 (TableFlyer) en 9 rondas. Muestra el formato funcionando: reglas arriba, cada lección con su evidencia, mensajes de error exactos, decisiones con su razón y una fila de eficacia por sesión. Se quitaron los nombres, las rutas y las notas personales.
